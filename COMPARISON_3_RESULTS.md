# Comparison 3: final activation-map projection only

Measured on 2026-09-05. Aligning the final interface substantially improves
English VoiceChat-space agreement and preserves intrinsic multilingual
retrieval, but restores only one English tool call in the six-case development
pilot. Russian speech produces no assistant response in this pilot.

## Candidate and selection

The candidate is `final-map-projection`. Its 636 canonical `encoder.*` tensors
are byte-identical to the original PT_ML safetensors and the Comparison 1
pass-through artifact. It inherits the complete PT_ML runtime configuration,
including 56 frames of left context. Only the FT_EN projection changes:

```text
h_E A_L ~= h_M; h_M B_L ~= h_E
W_proj,M = W_proj,F B_L^T
b_proj,M = W_proj,F b_L + b_proj,F
```

Both maps use training-set centering and identity-regularized ridge. The fit
uses 57,912 frames from 762 LibriSpeech `map_train` clips, paired with the frozen
Comparison 1 PT_ML cache. Regularization is selected by target-space R² on
21,660 frames from 285 speaker-disjoint `validation` clips. The selected
forward/reverse strengths are 0.001/0.1, with validation R² 0.439845/0.441524.
Their condition numbers are 30,530.6/7,128.1; these are not near-orthogonal maps.

Regularization pulls the linear part toward identity. The unpenalized affine
offset persists, so infinite regularization approaches a training-mean shift,
not the completely untouched interface. The zero-bias identity is scored
separately. The English agreement below is a development result on the same
speaker split used for selection, though selection uses a different target
space. The reserved LibriSpeech test split remains unencoded. FLEURS is used
only after selection, without refitting or tuning.

## Shared evaluation

| Metric | PT_ML pre | Map pre | PT_ML post Q8 | Map post Q8 |
|---|---:|---:|---:|---:|
| English VoiceChat-space R² | -0.700806 | -0.023870 | -0.701194 | -0.024096 |
| English VoiceChat-space cosine | 0.300820 | 0.540775 | 0.300750 | 0.540692 |

The pre-quantization paired R² improvement is +0.676937, 95% bootstrap CI
[+0.6705, +0.6827]; cosine improves by +0.239955, CI [+0.2385, +0.2413].
Quantization changes the candidate's R² by -0.000227 and cosine by -0.000083.

Intrinsic retrieval arrays and metrics are exactly unchanged from Comparison 1
within each precision stage. Historical centered FLEURS top-1 and MRR
differences have paired intervals containing zero. Post-quantization French
top-5 increases by 0.067669, CI [0.0075, 0.1278]; the other historical top-5
intervals contain zero.

The separate activation-map generalization test shows a limit: the reverse
map has R² around +0.29 on English FLEURS recordings but -0.312056 on German,
-0.532684 on French, and -0.666505 on Russian. These foreign scores improve on
the untouched interface but remain worse than predicting the target mean.
The target here is PT_EN's activation on the same recording, not a foreign
transcription or tool-call ground truth.

## Paired speech-to-action evaluation

The full four-row table is generated by `build_comparison()` and saved in
`.cache/experiments/voice-assistant-pilot-v2/analysis-through-comparison-3/`.
All rows use the same six semantic cases in English and Russian, frozen system
prompt, Q8 stage, runtime, environment, and 30-second response budget measured
from the end of each audio clip.

The original FT_EN control makes 4/6 exact English calls and 0/6 Russian calls.
Comparisons 1 and 2 (`lambda=1`) make no calls and produce no assistant turn.
Comparison 3 makes 1/6 exact English calls and 0/6 Russian calls. Its only
response is English `simple_1`: `math.factorial({"number": 5})`, followed by
the correct answer, 120, in English. The other eleven clips exhaust the
response budget without a model response. All twelve sessions complete without
transport errors.

The paired Russian-minus-English exact accuracy is -0.166667, 95% bootstrap
CI [-0.5, 0.0]. Russian success conditional on English success is 0/1. The
per-language response, tool attempt, well-formedness, name, argument, required
fact, and English-output scores are all 1/6 for English and 0/6 for Russian.
Per-case argument-type and value diagnostics remain in the scored result.

The small development pilot uses synthesized, single-speaker Russian audio.
These results establish neither reliable English tool calling nor a deployable
multilingual model. Preserved intrinsic retrieval does not establish that the
frozen language model understands the encoder's outputs.

## Reusable artifacts and verification

All paths below are relative to this repository's main checkout. Large files
remain ignored. The original fitting run and its manifests are unchanged.

- `.cache/experiments/comparison-3-final-map-v1/run.json`: fitting command,
  checkpoint revisions and hashes, complete metrics and artifact index.
- The same directory's `maps/final_activation_maps.safetensors` and
  `analysis/final_activation_maps.json`: both affine maps, selected penalties,
  singular spectra, conditioning, identity distance, cycle consistency, and
  FLEURS generalization diagnostics.
- Its `embeddings/{pre,post}_quantization.safetensors`: reusable evaluation
  arrays paired against the exact frozen Comparison 1 reference.
- Its `artifacts/final-map-projection/`: F32 encoder, folded `proj.*`, and
  featurizer tensors; the projection cannot be replaced by a container fallback.
- Its `deployment/final-map-projection-Q8_0.gguf`: evaluated deployment artifact.
- `.cache/experiments/voice-assistant-pilot-v2/final-map-projection-post-q8/`:
  speech evaluation command, server discovery, raw responses, and scored result.
- `.cache/experiments/comparison-3-final-map-v1-completion/completion.json`:
  completion evidence and hashes, including source/artifact validation,
  reproduction of both precision-stage metrics, tests, and runtime parity.

Runtime parity uses the actual Q8 artifact in the pinned deployment image and
the existing `test_question_16k.wav`. The research encoder and runtime agree on
85 frames. Worst sampled frame-zero discrepancy is 0.0527 embedding standard
deviations; mean/std discrepancies are 0.0001/0.0006. This passes the checker’s
documented 0.10 tolerance for a fitted projection, rather than its stricter
0.05 default for trained projections. The parity capture places the LLM on CPU
and retains GPU encoder execution; its short decoding cap does not affect the
full-clip encoder output. The speech evaluation itself uses the unchanged
frozen GPU runtime settings.
